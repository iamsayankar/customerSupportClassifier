# AI Fresher Technical Assignment – Customer Support Ticket Classifier

## 1. Project Overview
This project classifies customer support tickets into categories based on their descriptions.

The system uses:
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
- Streamlit

## 2. Problem Statement
A company receives customer support requests. The goal is to automatically predict the category of a new support ticket from its description.

Example:
- "I forgot my password" → Login Issue
- "The application shows an error" → Application Error
- "I need a sales report" → Report
- "I need to change my phone number" → Account Update
- "The application is very slow" → Performance

## 3. Dataset
The dataset is a self-created sample dataset containing 200 records and 5 categories.

Fields:
- ticket_id
- ticket_description
- category
- priority
- status

Categories:
- Login Issue
- Application Error
- Report
- Account Update
- Performance

## 4. Data Preprocessing
The project:
1. Reads the CSV using Pandas.
2. Checks missing values.
3. Checks and removes duplicate records.
4. Handles missing text/category values.
5. Converts ticket text to lowercase.
6. Removes unnecessary characters.
7. Removes extra spaces.

## 5. Exploratory Data Analysis
The project calculates:
- Total ticket count
- Tickets by category
- Tickets by priority
- Tickets by status

Charts:
- Category distribution
- Priority distribution

## 6. Machine Learning Model

### Selected approach
TF-IDF + Logistic Regression.

### Why?
TF-IDF converts text into numerical features based on word importance. Logistic Regression is a simple and effective classification algorithm for text classification and is easy to explain for a fresher-level project.

Pipeline:
Ticket Description
→ Text Cleaning
→ TF-IDF
→ Logistic Regression
→ Predicted Category

## 7. Training and Testing
The dataset is split into:
- 80% training data
- 20% testing data

The model is evaluated using:
- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

Actual metric values are generated by `train.py` and saved to `model/metrics.csv`.
